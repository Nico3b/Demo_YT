# Sudoku

A small Sudoku game that runs directly in your browser. It uses plain HTML, CSS,
and JavaScript, so there is nothing to install.

## Play

Open `index.html` in a web browser. Select an empty square and enter a number
using the number buttons or your keyboard. Use **Check puzzle** to see whether
you have completed it correctly, or **Reset puzzle** to start over.

Choose Easy, Moderate, Hard, or Expert from the start popup. After a 3-second
countdown, the timer starts automatically. Use **Change** to choose a different
level or **Reset puzzle** to restart the current one; both start a fresh countdown.
The timer stops when you check a completed solution.

Each level has its own color theme, which changes when that level starts.

Each row, column, and 3 × 3 square must contain the numbers 1 to 9 without
repeats.
